We grade the process and the reasoning, not the model's numbers

Results vary by provider and model, so a lower accuracy will not cost you points if you measured it correctly and explained it. Reflections should cite numbers from your own runs. Answers that could have been written without running the notebook earn little credit.

Criteria by part

1

Prompt anatomy

10 pts
  • Prompt versions v1 → v3 each run and logged under their own tag. v3 contains a role, constraints, and an explicit JSON schema, and its schema check is reported.4
  • Robustness check run (5 runs at temperature 0.7) with the pass rate reported.2
  • Reflection names the change with the largest effect and a concrete mechanism that would fix the remaining failures.4

Common deductions: skipping a version, v3 output that doesn't parse, or "make the prompt clearer" as the fix.

2

Zero-shot vs few-shot

12 pts
  • Few-shot job-title prompt with 3–4 examples that cover a none case, title-only output, and the Name | Title | Company format.5
  • Multi-label genre prompt restricted to the given label set, with mean Jaccard reported.4
  • Reflection separates accuracy from format consistency, discusses the hardest item, and addresses what an 8-item test set can and can't tell you.3

Cap: using any test sentence as a few-shot example is test-set leakage. The part is then capped at 5 / 12.

3

Model parameters

8 pts
  • Temperature diversity table and plot produced.2
  • max_tokens sweep run, with truncation identified from finish_reason.2
  • Length controlled through the prompt at max_tokens=20, finishing with stop.2
  • Reflection picks a temperature for each use case and explains why max_tokens is a poor length control.2

Common deduction: "fixing" length by raising max_tokens.

4

Hallucinations & guardrails

10 pts
  • Guarded prompt that answers only from the passage, replies with the exact string NOT IN CONTEXT when it can't, and quotes its evidence when it can.5
  • Both prompts scored for abstention. The guarded prompt reaches at least 4 / 5.2
  • Reflection quotes a specific hallucination from your run and proposes at least one safeguard beyond prompting.3
5

Role-based prompting

4 pts
  • A fourth role of your own added and run.2
  • Reflection contrasts the roles with specific points from the outputs and proposes how to combine them.2

Common deduction: "the tone was different" with no specifics.

6

Reasoning strategies

12 pts
  • Two-stage answer extraction implemented.3
  • Selection-inference implemented: decompose, answer the sub-question, then answer with the new fact in context.4
  • All four strategies compared on accuracy and calls per question.2
  • Reflection classifies the errors (interpretation vs arithmetic) and weighs the extra cost.3

Common deduction: strategies C and D must be separate calls that pass context forward. A single prompt imitating them loses 2 points each.

7

Chaining & chunking

8 pts
  • Entity → summary → sentiment chain runs end to end with JSON intermediates.2
  • map_reduce_summary implemented: summarize each chunk, then merge into a final summary with a Topic: line.4
  • Bonus question answered: why split on sentence boundaries, and why overlap helps.2

Common deduction: a reduce step that just concatenates the chunk summaries.

8

Embeddings

8 pts
  • Nearest-label zero-shot classifier implemented, with accuracy reported.4
  • Richer label descriptions tried and compared with the originals.2
  • Reflection weighs embeddings against LLM prompting on cost, latency, and adaptability. If you used the TF-IDF fallback, explain its limits.2
9

Capstone: Lost & Found matching

20 pts
  • Retrieval-only baseline reported.2
  • Normalization prompt with a fixed schema that invents no details and keeps personal identifiers out. Recall@k compared against the baseline.5
  • Rerank prompt that rules out candidates conflicting on hard attributes and can answer NO_MATCH.5
  • Results table complete, including LLM call counts.3
  • Memo (≤ 200 words) covers the staff workflow and human role, the 50% goal, scale and cost, PII handling, and keeping the vector index up to date.5

Results credit: ≥ 9 / 12 correct with no false matches earns full credit. 7–8 correct costs 2 points. Matching L12 to any item costs 2 points.

10

Prompt template & wrap-up

8 pts
  • Template includes a role, inputs, an output schema, at least two real safety rules, and filled-in evaluation numbers.4
  • prompt_log.csv exported.1
  • Final reflection answers all three questions using evidence from your own results.3

Common deduction: leaving the template's eval fields as null.

Deductions

API key pasted anywhere in the notebook. Rotate the key immediately.−5
Notebook submitted unrun, or with cells that error.−5
Reflection that cites no numbers from your own runs, per reflection.−1 each, max −5
